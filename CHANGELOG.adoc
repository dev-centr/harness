== 2026-09-10 — Plan-stack dock panel

* Added cross-cutting **Plan stack** panel (above the temporal scrubber) — not a Linear/Grid/Tree peer.

== 2026-09-10 — Desk view modes (Linear / Grid / Tree)

* Rebuilt the desk UI to lock **discussion cadence** (main chat) vs **work cadence** (workers mailbox + fork drill-in).
* Three shell view modes: **Linear** (Cursor-like discussion sidebar + transcript), **Grid** (spatial task tiles + visible discussion), **Tree** (L→R spawn tree with `+` → `POST /api/spawn`).
* Temporal scrubber stays cross-cutting (global or subtree scope) across all modes; removed the old serialized wall toggle.

== 2026-09-10 — Deferred push for parallel task nodes

* Added `GitCloseout` on each node (`commit-only`, `coordinator-batch`, `per-node`, `off`).
* Task / discussion leaves default to **coordinator-batch** / **commit-only**; coordinator stays **per-node** (owns wave-end push).
* Spawn writes a `system` close-out brief into `chat.jsonl` and returns `closeout` on `/api/spawn` and `/api/provider/session|turn` so inherited always-on push rules cannot silently win.
* Cuts remote CI rebuild storms when many workers would otherwise each `git push`.

* Renamed `HORNET_AVAIL_RAM_MB` to `HARNESS_AVAIL_RAM_MB`.
* The repository moved from `dev-centr/hornet` to `dev-centr/harness`; GitHub redirects the old URL.
